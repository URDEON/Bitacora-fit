## Si tienes la entrega anterior instalada

La clave privada de la APK original 5.0.1 no estaba incluida en su entrega. Este instalador utiliza otra firma de depuración, por lo que Android no permite aplicarlo como actualización sobre esa APK.

1. Abre la aplicación anterior y exporta un respaldo JSON desde **Ajustes**. Guarda ese archivo fuera de la aplicación y comprueba que esté disponible.
2. Una vez conservado el respaldo, desinstala la versión anterior e instala esta APK.
3. Importa el respaldo JSON desde **Ajustes** para recuperar tus registros.

El archivo `Bitacora-Fit-Pro-5.0.2.apk.sha256` contiene el checksum de esta APK. Se verifican la firma, la integridad ZIP y la coincidencia de los recursos web compilados con los incluidos en el APK. No se ha probado en un teléfono físico.
