# APK de Bitácora Fit Pro 5.0.4

[Descargar APK para Android](./Bitacora-Fit-Pro-5.0.4.apk)

Si la descarga del APK queda pendiente en el navegador, prueba la [descarga alternativa en ZIP](./Bitacora-Fit-Pro-5.0.4-instalar.zip). Abre el enlace en el navegador del teléfono; después extrae el ZIP desde **Archivos → Descargas** y abre el APK que contiene. Ambos archivos contienen exactamente la misma aplicación.

Compatible con Android 7.0 o posterior. Abre el archivo en el teléfono y permite instalar aplicaciones desde el navegador o gestor de archivos si Android lo solicita.

Esta compilación incorpora el Home con carrusel circular, hero contextual, paleta coherente e identidad de pulso de la versión 5.0.4. Conserva el entrenamiento guiado y el funcionamiento sin conexión.

## Actualizar desde la APK 5.0.2 o 5.0.3 de este repositorio

La firma y el identificador de la aplicación se conservan. Instala esta APK encima de la versión 5.0.2 o 5.0.3, sin desinstalarla, para conservar tus registros. Siempre puedes exportar un respaldo JSON desde **Ajustes** antes de actualizar.

## Si tienes la entrega original 5.0.1 instalada

La clave privada de la APK original 5.0.1 no estaba incluida en su entrega. Los instaladores de este repositorio utilizan otra firma de depuración, por lo que Android no permite aplicarlos como actualización sobre aquella APK.

1. Abre la aplicación anterior y exporta un respaldo JSON desde **Ajustes**. Guarda ese archivo fuera de la aplicación y comprueba que esté disponible.
2. Una vez conservado el respaldo, desinstala la versión anterior e instala esta APK.
3. Importa el respaldo JSON desde **Ajustes** para recuperar tus registros.
