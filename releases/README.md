# APK de Bitácora Fit Pro 5.1.0

[Descargar APK para Android](./Bitacora-Fit-Pro-5.1.0.apk)

Si la descarga del APK queda pendiente en el navegador, prueba la [descarga alternativa en ZIP](./Bitacora-Fit-Pro-5.1.0-instalar.zip). Abre el enlace en el navegador del teléfono; después extrae el ZIP desde **Archivos → Descargas** y abre el APK que contiene. Ambos archivos contienen exactamente la misma aplicación.

Compatible con Android 7.0 o posterior. Abre el archivo en el teléfono y permite instalar aplicaciones desde el navegador o gestor de archivos si Android lo solicita.

Esta compilación incorpora el diseño grafito con vidrio neutro, personalización de diez acentos HEX, historial por medición y registro rápido inferior. Añade Finanzas en CLP, Notas, Tareas y Herramientas; conserva el entrenamiento guiado y los registros existentes.

## Actualizar desde la APK 5.0.2, 5.0.3, 5.0.4 o 5.0.5 de este repositorio

La firma y el identificador de la aplicación se conservan. Instala esta APK encima de la versión 5.0.2, 5.0.3, 5.0.4 o 5.0.5, sin desinstalarla, para conservar tus registros. Siempre puedes exportar un respaldo JSON desde **Ajustes** antes de actualizar.

## Respaldos

- Fit conserva su respaldo JSON existente: **Herramientas → Apariencia y respaldos → Copias de seguridad de Fit**.
- Finanzas, Notas y Tareas se exportan e importan juntas desde **Herramientas → Respaldo de Finanzas y Notas**.
- Apariencia tiene su propia configuración exportable. Los tres archivos mantienen sus datos separados.

## Si tienes la entrega original 5.0.1 instalada

La clave privada de la APK original 5.0.1 no estaba incluida en su entrega. Los instaladores de este repositorio utilizan otra firma de depuración, por lo que Android no permite aplicarlos como actualización sobre aquella APK.

1. Abre la aplicación anterior y exporta un respaldo JSON desde **Ajustes**. Guarda ese archivo fuera de la aplicación y comprueba que esté disponible.
2. Una vez conservado el respaldo, desinstala la versión anterior e instala esta APK.
3. Importa el respaldo JSON desde **Ajustes** para recuperar tus registros.

## Verificación

El archivo `Bitacora-Fit-Pro-5.1.0.apk.sha256` contiene el checksum de esta APK. Se verifican la firma, la compatibilidad de actualización desde 5.0.5, la integridad ZIP y la coincidencia de los recursos web compilados con los incluidos en el APK. No se ha probado en un teléfono físico. Los instaladores anteriores se conservan en esta carpeta.
